# -Terraria_backup_tool
使用gemini3.1pro整的泰拉瑞亚存档自动备份工具，随缘分享，个人自用，可能不会再更新

Terraria Save Auto-Backup Tool, built with Gemini 3.1 Pro. Shared casually, for personal use only and may not receive further updates.

本工具是一个基于“时间点快照（Snapshot）”架构的泰拉瑞亚存档自动备份程序。它摒弃了容易导致数据错位的散装文件备份法，将人物存档（包含 .map 小地图探索数据）与世界存档在同一时刻打包隔离。这种设计从根本上杜绝了回档时可能产生的“人物与世界状态不同步（例如利用时间差刷物品的 Bug）”问题。支持定时自动备份、历史快照库管理、自动垃圾回收（清理旧存档）以及标准的 ZIP 压缩包导入导出。

使用注意:
1.回档覆盖不可逆：执行“一键回档”会无情且彻底地覆盖游戏目录下的当前存档。请务必确保在执行回档时，游戏处于主菜单界面或已完全关闭。如果在游玩过程中强行回档，会因文件被系统占用导致写入失败，甚至造成存档永久损坏。

2.地图数据绑定逻辑：程序在底层会自动寻找与 .plr 人物文件同名的文件夹来备份全图视野。绝对不要在游戏外随意重命名存档文件，这会破坏程序的映射逻辑，导致回档后人物地图变黑。

3.自动清理的风险：如果启用了“垃圾回收”功能，程序会根据设定的阈值，自动抹除备份目录下的旧文件夹。因此，绝对不要将任何与备份无关的私人文件放在备份根目录中，它们可能会被当成旧快照被程序误删。

4.关于打包后的杀毒误报：如果你使用 PyInstaller 将本 Python 脚本打包成了 .exe，由于其“自解压释放文件并执行”的底层运作机制与诸多木马病毒高度重合，极易遭到 Windows Defender 或其他杀毒软件的拦截或直接删除。实际上这不是代码有毒，而是打包机制的原罪，请手动将其加入信任白名单。
